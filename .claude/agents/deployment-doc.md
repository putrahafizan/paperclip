## Deployment Steps

### Deploy Pertama Kali

[jika Docker:]
```bash
cd /var/www/[nama-project]

# Pull image terbaru (jika pakai registry)
# docker compose pull

# Build dan jalankan
docker compose up -d --build

# Cek semua container berjalan
docker compose ps
```

[jika ada migrasi database — Node.js:]
```bash
# Jalankan migrasi (pastikan DB sudah running)
docker compose exec app node src/db.js
# atau: npm run migrate
```

[jika ada migrasi database — Laravel:]
```bash
docker compose exec app php artisan migrate --force
docker compose exec app php artisan db:seed --force  # jika ada seeder
```

[jika ada migrasi database — Python:]
```bash
docker compose exec app alembic upgrade head
```

### Update / Redeploy

```bash
cd /var/www/[nama-project]
git pull origin main

[jika Docker:]
docker compose up -d --build
docker compose exec app [migration command]  # jika ada perubahan DB

[tanpa Docker — Node.js:]
npm install --production
pm2 reload [nama-app]

[tanpa Docker — Laravel:]
composer install --no-dev --optimize-autoloader
php artisan migrate --force
php artisan config:cache && php artisan route:cache
sudo systemctl reload nginx
```

### Verifikasi Post-Deploy

```bash
# Cek aplikasi berjalan
curl -s http://localhost:[port]/health | head -5

[jika Docker:]
# Cek logs jika ada masalah
docker compose logs --tail=50 app
```

## Rollback Procedure

### Rollback ke commit sebelumnya

```bash
cd /var/www/[nama-project]

# Lihat commit history
git log --oneline -10

# Rollback ke commit tertentu
git checkout [COMMIT_HASH]

[jika Docker:]
docker compose up -d --build
# Jika ada perubahan DB yang perlu di-rollback:
docker compose exec app [rollback command sesuai stack]

[tanpa Docker:]
npm install --production && pm2 reload [nama-app]  # Node.js
php artisan migrate:rollback && supervisor restart  # Laravel
```

### Rollback database (jika perlu)

> ⚠️ Selalu backup database sebelum migrate di production.

```bash
# Backup sebelum rollback:
[jika Docker + PostgreSQL:]
docker compose exec db pg_dump -U [user] [dbname] > backup_$(date +%Y%m%d_%H%M%S).sql

[jika Docker + MySQL:]
docker compose exec db mysqldump -u [user] -p[pass] [dbname] > backup_$(date +%Y%m%d_%H%M%S).sql
```

### Jika PLATFORM = github

```yaml
<!-- SECTION:cicd -->
## CI/CD — GitHub Actions

Buat file `.github/workflows/deploy.yml`:

```yaml
name: Deploy to Production

on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Deploy via SSH
        uses: appleboy/ssh-action@v1
        with:
          host: ${{ secrets.SERVER_HOST }}
          username: ${{ secrets.SERVER_USER }}
          key: ${{ secrets.SERVER_SSH_KEY }}
          script: |
            cd /var/www/[nama-project]
            git pull origin main
            docker compose up -d --build
            docker compose exec -T app [migration command]
            curl -s http://localhost:[port]/health
```

### Secrets yang perlu dikonfigurasi di GitHub:
- `SERVER_HOST` → IP atau domain server
- `SERVER_USER` → username SSH (contoh: ubuntu, deploy)
- `SERVER_SSH_KEY` → private key SSH (format PEM, tanpa passphrase)

### Setup deploy key (opsional, lebih aman):
```bash
# Generate key di server
ssh-keygen -t ed25519 -C "deploy@[nama-project]" -f ~/.ssh/deploy_key

# Tambahkan public key ke GitHub repository:
# Settings → Deploy keys → Add deploy key → paste ~/.ssh/deploy_key.pub

# Tambahkan private key sebagai GitHub Secret:
# Settings → Secrets → Actions → SSH_KEY → paste ~/.ssh/deploy_key
```

## CI/CD — GitLab CI

Buat file `.gitlab-ci.yml` di root:

```yaml
stages:
  - deploy

deploy_production:
  stage: deploy
  image: alpine:latest
  before_script:
    - apk add --no-cache openssh-client
    - eval $(ssh-agent -s)
    - echo "$SSH_PRIVATE_KEY" | tr -d '\r' | ssh-add -
    - mkdir -p ~/.ssh && chmod 700 ~/.ssh
    - ssh-keyscan $SERVER_HOST >> ~/.ssh/known_hosts
  script:
    - ssh $SERVER_USER@$SERVER_HOST "
        cd /var/www/[nama-project] &&
        git pull origin main &&
        docker compose up -d --build &&
        docker compose exec -T app [migration command]
      "
  only:
    - main
```

### Variables yang perlu dikonfigurasi di GitLab:
GitLab → Project → Settings → CI/CD → Variables

| Variable | Value | Protected | Masked |
|----------|-------|-----------|--------|
| SERVER_HOST | IP atau domain | ✓ | ✗ |
| SERVER_USER | username SSH | ✓ | ✗ |
| SSH_PRIVATE_KEY | private key PEM | ✓ | ✓ |
<!-- /SECTION:cicd -->
